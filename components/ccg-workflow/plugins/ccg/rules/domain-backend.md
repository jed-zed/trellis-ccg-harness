# Domain Backend Rule

Use this rule for API design, service logic, data flows, persistence, jobs, and integration boundaries.

- Read `ccg-role-routing.md` and resolve the `backend` provider before assigning
  backend drafting or analysis.
- Preserve local architecture, error handling, transactions, and tests.
- Use the configured backend provider for design alternatives, edge cases, or
  second-pass review when useful.
- Codex applies the final workspace edits and verifies them.
- Run focused project tests before delivery.
