## Not covered

These offline fixtures deliberately construct synthetic evidence. They do not prove a live
Claude model round or a GPT Pro send/ZIP round. Native plugin parsing is a real Claude binary
check, not model execution. Browser calls, model calls and global configuration changes in
this addon task were zero. Actual host identity substitution inside a model-driven skill
still needs the live host round; syntax is based on the official documented substitution.

A minimal later live acceptance uses the original Claude CCG route on a synthetic project,
loads this addon, submits one independently authorized synthetic ZIP through the existing
approved agent-browser-cli channel, waits locally, imports the exact response, reviews it,
and records local acknowledgement. Missing approved tabs/authentication/normal tool permission
must remain explicit user barriers. Do not change credentials, accounts or browser grants.

The official Browser Service MCP adapter is a different interface and is not substituted.
This addon uses Claude's existing Bash access to the fixed CLI transport, registers no MCP,
and does not claim an MCP-only file-upload implementation. Linux/macOS runtime, batch rounds
and same-conversation follow-up APIs remain outside this initial addon acceptance.
