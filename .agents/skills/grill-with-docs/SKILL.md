Run a grilling session while applying domain modeling:

1. Read [references/grilling.md](./references/grilling.md) and follow its
   one-question-at-a-time interview loop.
2. Read
   [references/domain-modeling.md](./references/domain-modeling.md) and apply
   its glossary, code cross-check, and ADR discipline throughout the interview.
3. Do not implement the resulting plan until the user confirms that shared
   understanding has been reached.
