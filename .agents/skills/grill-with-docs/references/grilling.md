# Grilling

Interview the user relentlessly about every aspect of the subject until both
sides reach a shared understanding. Walk down each branch of the decision tree,
resolving dependencies between decisions one by one. For each question, provide
a recommended answer.

Ask questions one at a time and wait for feedback before continuing. Multiple
questions at once are bewildering.

If a fact can be found by exploring the environment, look it up instead of
asking. Decisions belong to the user: put each one to them and wait for the
answer.

Do not act on the plan until the user confirms that shared understanding has
been reached.
