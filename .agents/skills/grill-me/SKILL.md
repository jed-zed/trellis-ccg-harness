# Grill Me

Question the user about every relevant part of the plan or design. Follow each
decision branch, resolve dependencies in order, and recommend an answer with
every question.

Ask exactly one question at a time and wait for the user's response.

Look up facts available in the current environment instead of asking the user.
Leave decisions to the user and wait for explicit answers.

Do not implement the plan until the user confirms that shared understanding has
been reached.
